# Фронтенд для дизайнера

Интерактивный курс фронтенд-разработки для продуктового дизайнера: теория простым языком,
аналогии с Figma, плейграунды с ползунками, задания с автопроверкой, квизы, прогресс и навыки.

## Как устроен проект

```
content/                ← КОНТЕНТ (его можно дописывать, не трогая код)
  modules/*.json        ← один файл = один модуль с уроками
  glossary.json         ← глоссарий «дизайнер ↔ разработчик»
src/
  styles/tokens.css     ← все дизайн-токены: цвета, отступы, шрифты, темы
  styles/global.css     ← стили компонентов (только через var(--токен))
  lib/                  ← логика: прогресс, проверки заданий, тема
  components/, widgets/ ← редактор кода, квиз, ползунки, сравнитель платформ, чек-лист
  pages/                ← экраны сайта
scripts/check-content.mjs ← проверка контента на ошибки
```

## Запуск на своём компьютере

1. Установите **Node.js** (версия 20 или новее): https://nodejs.org → кнопка LTS.
2. Откройте Терминал в папке проекта и установите зависимости (один раз):
   ```
   npm install
   ```
3. Запустите сайт:
   ```
   npm run dev
   ```
4. Откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173).
   Правки в коде и в `/content` видны сразу, без перезагрузки.
5. Остановить сервер — `Ctrl + C` в терминале.

## Как дописать урок

1. Откройте файл модуля в `content/modules/`, например `m04-layout.json`.
2. Скопируйте структуру заполненного урока из `m03-css.json` (поля `theory`, `figma`, `widgets`, `task`, `quiz`, `practice`)
   и уберите у урока `"stub": true`. У модуля поменяйте `"status": "stub"` на `"ready"`.
3. Проверьте контент: `npm run check-content`.

Типы проверок в заданиях (`task.checks`): `exists`, `notExists`, `count`, `style` (вычисленный стиль),
`text`, `attr`, `source` (регулярное выражение по коду). Полное описание — в `src/lib/types.ts`.

## Деплой на Vercel (бесплатно)

1. Создайте аккаунт на https://github.com и новый пустой репозиторий.
2. Загрузите проект в репозиторий (в терминале, в папке проекта):
   ```
   git init
   git add .
   git commit -m "Первая версия курса"
   git branch -M main
   git remote add origin https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
3. Зайдите на https://vercel.com → **Sign up with GitHub**.
4. **Add New → Project** → выберите репозиторий → **Import**.
5. Vercel сам определит Vite. Настройки по умолчанию подходят: Build Command `npm run build`, Output Directory `dist`.
   Нажмите **Deploy**.
6. Через минуту сайт будет доступен по адресу вида `https://ваш-проект.vercel.app`.
   Каждый следующий `git push` будет обновлять сайт автоматически.

Файл `vercel.json` нужен, чтобы прямые ссылки на уроки (например, `/lesson/m01-web/l1-browser`) открывались, а не давали 404.

## Прогресс

Прогресс хранится в браузере (localStorage). Чтобы перенести его на телефон или другой компьютер:
страница **«Прогресс»** → «Экспорт в JSON» → на другом устройстве «Импорт из JSON».
